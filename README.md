# 🏛️ San Jacinto Estate Simulation

## 📄 Abstract

This project is an educational 3D simulation of the historical Hacienda San Jacinto, built using Python, Pygame, and PyOpenGL. The project immerses users in a virtual recreation of the estate with dynamic lighting, real-time interaction, audio effects, and configurable gameplay. It was created as part of a university course in computer graphics programming.

## 🔑 Keywords

Python, Pygame, OpenGL, 3D Simulation, Game Development, Educational Project, Interactive Visualization, PyInstaller

## 👋 Introduction

The San Jacinto Estate Simulation allows users to explore a 3D environment inspired by the iconic Hacienda San Jacinto. Users interact through a menu-driven interface, and navigate the scene using keyboard or joystick. The system features a dynamic day/night cycle, environmental sounds, and a music controller.

Built by students in their third semester of computer systems engineering, this project demonstrates practical applications of game loops, rendering, OpenGL model loading, and sound management in Python.

## 🖥️ Installation and Execution

### Run from Source

1. Clone the repository **with Git LFS** (the `.obj` models are stored in LFS; without it the
   files are only small text pointers and the scene cannot load):

```bash
git lfs install
git clone https://github.com/Jessuapapu/Proyecto-Programacion-Grafica.git
cd Proyecto-Programacion-Grafica
git lfs pull
```

2. (Recommended) create a virtual environment:

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate      # Linux / macOS
```

3. Install the dependencies. If the original `pygame` package is installed, remove it first,
   because it conflicts with `pygame-ce`:

```bash
pip uninstall -y pygame
pip install -r requirements.txt
```

4. Run the project:

```bash
python main.py
```

#### Troubleshooting

| Error | Cause / fix |
|-------|-------------|
| `Failed to build 'pygame'` / `No module named 'setuptools._distutils.msvccompiler'` | The original `pygame` has no installer for Python 3.14. Use `pygame-ce` (already in `requirements.txt`). |
| `Invalid requirement` when running `pip install -r requirements.txt` | Old `requirements.txt` was saved as UTF-16. The current one is plain UTF-8. |
| `NullFunctionError: glutInit` | Old versions called GLUT, which PyOpenGL does not ship on Windows. GLUT is no longer used. |
| "... is a Git LFS pointer" | Run `git lfs install` and `git lfs pull`. |

### Run as Executable (.exe)

To generate the Windows executable:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed ^
--add-data "Recursos;Recursos" ^
--add-data "Audio;Audio" ^
--add-data "Clases;Clases" ^
--add-data "Escenas;Escenas" ^
--add-data "modelosObj;modelosObj" ^
main.py
```

Then run:

```
dist/main.exe
```

## 🎮 Controls

- WASD — Move
- Mouse / Right joystick — Look around
- Left joystick — Move
- Shift / Space — Descend / Ascend
- ESC / Start button — Pause menu (continue, settings: volume, sensitivity, speed and sky mode, exit)
- Joystick — Supported

## 📦 Requirements

- Python 3.10 – 3.15
- pygame-ce ≥ 2.5.8 (drop-in replacement for Pygame, imported as `pygame`)
- PyOpenGL ≥ 3.1.9
- NumPy ≥ 1.26
- Pillow ≥ 10.0
- PyInstaller ≥ 6.0 (only to build the executable)
- Git LFS (to download the 3D models)

## 💡 Lighting

- Continuous day/night cycle (5 s = 1 simulated hour, the tour starts at 9:00).
- Sky mode selectable in the main menu settings or in the pause menu: day/night cycle or always day (fixed at 11:00).
- Directional sun that rises, crosses the sky and sets, with warm light at sunrise/sunset.
- Soft moonlight at night, sky fill light and hemispheric ambient light.
- Atmospheric fog whose color follows the time of day; the day and night skyboxes blend smoothly.
- Per-pixel lighting (GLSL 1.20). If the graphics card cannot compile the shader, the
  fixed-function OpenGL lighting is used automatically.
- All parameters (colors, intensities, cycle speed) are at the top of `Escenas/Iluminacion.py`.

## 🗺️ Map, terrain and trees

Inspired by photos of the real Hacienda San Jacinto (dry tropical forest, red clay grounds):

- **Terrain with relief** (`Escenas/Terreno.py`): flat area around the hacienda, corrals and
  horses; gentle rolling ground and low hills in the field; a forested ridge on the horizon.
  Red clay grounds around the house and next to it, and dirt roads to the entrance and the corrals.
  The camera follows the ground when walking over hills.
- **Ground textures**: a large color map plus a fine repeating detail texture (grass / soil)
  applied by the shader in world coordinates.
- **Low-poly trees** (`Clases/ArbolesLowPoly.py`), generated by code: *guanacaste* (wide
  umbrella crown), *acacia* (tiered crown), round leafy trees, young trees, shrubs and a
  low-detail version for the horizon forest. About 2,400 trees are merged into a few GPU
  buffers so they render fast. Trunks have collision with the camera.
- **Hacienda textures**: whitewashed walls with a gray-blue skirting band (zócalo), weathered
  clay roof tiles and a gray-blue concrete corridor floor.

The map data lives in `modelosObj/Terreno/`. To change it (hills, roads, red grounds, forest
density...) edit the parameters at the top of `Recursos/Herramientas/generar_mapa.py` and run:

```bash
python Recursos/Herramientas/generar_mapa.py
python Recursos/Herramientas/generar_texturas.py   # hacienda textures
```

## 🏛️ Hall of Heroes (inside the hacienda)

Recreation of the museum room "Sala de los Héroes de la Batalla" (`Escenas/Museo.py`):

- Sculpted bronze busts (smooth meshes with patina in the hollows, generated by
  `Recursos/Herramientas/generar_bustos.py`; regenerating them needs `scikit-image`) on marble pedestals with engraved names: **General Miguel Vélez Morazán**,
  **General José Dolores Estrada** and **Teniente Adán Espinoza Solís** (names from the pedestal
  plaques and from El 19 Digital's description of the museum).
- Framed portraits with labels and a room sign: "Héroes de la Batalla de San Jacinto –
  14 de septiembre de 1856".
- Terracotta tile floor, red baseboard, wooden beam and cane ceiling and interior lamp light.
- Names, positions and images are in `modelosObj/Museo/museo.json` (edit the `nombre` fields).
